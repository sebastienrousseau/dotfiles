# Support

Thanks for using dotfiles. This page tells you where to go for what.

## Before you ask

1. **Search existing issues** — `https://github.com/sebastienrousseau/dotfiles/issues?q=` — most first-time questions have been answered.
2. **Try the doctor** — `dot doctor` runs the built-in health checks and often surfaces the root cause with a suggested fix.
3. **Read the runbooks** — [`docs/operations/`](docs/operations/) has runbooks for maintenance, drift, migration, and release.
4. **Read the guides** — [`docs/guides/`](docs/guides/) has install, theming, and platform-specific troubleshooting (macOS, Linux, WSL2+Nix).

## Where to ask

| I want to… | Go here |
|---|---|
| Report a bug | [GitHub Issues](https://github.com/sebastienrousseau/dotfiles/issues/new/choose) — pick the bug template |
| Request a feature | [GitHub Issues](https://github.com/sebastienrousseau/dotfiles/issues/new/choose) — pick the feature template |
| Ask a usage question | [GitHub Discussions](https://github.com/sebastienrousseau/dotfiles/discussions) — the *Q&A* category |
| Report a **security** issue | Follow [`SECURITY.md`](SECURITY.md) — **do not** open a public issue |
| Report Code of Conduct concerns | [`conduct@sebastienrousseau.com`](mailto:conduct@sebastienrousseau.com) |
| Suggest documentation improvements | Open a PR or issue — small fixes welcome without preamble |

## Response expectations

This is a solo-maintained project ([see governance](GOVERNANCE.md)).
Realistic response windows on a good week:

- **Security issues** — 48 hours acknowledgement, per [`SECURITY.md`](SECURITY.md)
- **Bug reports** — 3–7 days initial triage
- **Feature requests** — reviewed weekly; larger asks may need an RFC (see [`docs/GOVERNANCE.md`](docs/GOVERNANCE.md))
- **Q&A discussions** — best-effort; other contributors often reply first

If you need a faster response for something you're using in production, please say so in the issue — it helps prioritise.

## Contributing back

If your question exposes a documentation gap or a bug, a PR is
appreciated. See [`CONTRIBUTING.md`](CONTRIBUTING.md) for the
short-form contribution flow and [`docs/GOVERNANCE.md`](docs/GOVERNANCE.md)
