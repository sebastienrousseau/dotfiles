# Raycast

This directory stores Raycast preferences export/import files.

1. Open Raycast.
2. Export settings: `Raycast Settings -> Advanced -> Export Settings`.
3. Save the file under `~/.config/raycast/`, then run `dot config add <file>` to copy it into the source (`defaults/dot_config/raycast/`).

To restore, import the saved file from Raycast settings.
